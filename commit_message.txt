⚡ Bolt: [performance improvement] Added React.memo and fixed CSS

💡 What: Wrapped React Three Fiber repeating components with React.memo and fixed CSS build failure.
🎯 Why: In components rendering React Three Fiber `<Canvas>` elements, frequent parent state updates cause the entire Three.js sub-tree to be re-evaluated by React. This causes massive performance bottlenecks.
📊 Impact: Prevents massive Three.js sub-tree updates when parent state changes. Reduces UI lag and GPU strain.
🔬 Measurement: Verified there are no unnecessary re-renders. Ran lint, test and build.
