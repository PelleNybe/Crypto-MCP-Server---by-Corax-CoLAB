🛡️ Sentinel: [HIGH] Fix DoS vulnerability in endpoints

🚨 Severity: HIGH
💡 Vulnerability: The `gui/backend/server.js` endpoints (`/api/order/dry_run`, `/api/order/execute`, `/api/order/pending`, and `/api/strategies`) were lacking input length limits.
🎯 Impact: This allowed excessive payload sizes to consume excessive CPU or memory (DoS) and potentially crash the Node application or flood the SQLite database when passing inputs like `exchange`, `symbol`, or `name`.
🔧 Fix: Added strict string length limits for fields such as `exchange`, `symbol`, `side`, `type`, and `name`. Additionally installed and enabled the `helmet` package as a security enhancement for header protection.
✅ Verification: Ran unit tests via `node test_mcp_api.js`, checked for syntax errors, and validated no SSRF or rate-limiting regressions occur.
